# 19: Channels Basics

## What Is This Project About?

This module teaches you the fundamentals of Go channels for goroutine communication.

## Key Concepts

- **Unbuffered channels**: Synchronous send/receive
- **Buffered channels**: Async with capacity
- **Closing channels**: Signaling completion
- **Range over channels**: Receiving until closed

## How to Run

```bash
go run ./cmd/dev/main.go
```
