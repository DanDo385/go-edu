# 20: Select, Fan-in, Fan-out

## What Is This Project About?

This module teaches you advanced channel patterns using select for multiplexing.

## Key Concepts

- **select statement**: Waiting on multiple channels
- **Fan-out**: Distributing work to workers
- **Fan-in**: Merging multiple channels
- **Timeouts**: Using select with time.After

## How to Run

```bash
go run ./cmd/dev/main.go
```
