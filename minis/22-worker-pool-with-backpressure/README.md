# 22: Worker Pool with Backpressure

## What Is This Project About?

This module teaches you how to build a worker pool with backpressure handling.

## Key Concepts

- **Backpressure**: Slowing producers when consumers lag
- **Bounded queues**: Fixed-size work queues
- **Graceful degradation**: Handling overload
- **Rate limiting**: Controlling throughput

## How to Run

```bash
go run ./cmd/dev/main.go
```
