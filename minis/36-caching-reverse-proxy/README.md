# 36: Caching Reverse Proxy

## What Is This Project About?

This module teaches you how to build a caching reverse proxy.

## Key Concepts

- **Reverse proxy**: Forwarding requests
- **Response caching**: Storing responses
- **Cache invalidation**: TTL, manual purge
- **httputil.ReverseProxy**: Standard library proxy

## How to Run

```bash
go run ./cmd/dev/main.go
```
