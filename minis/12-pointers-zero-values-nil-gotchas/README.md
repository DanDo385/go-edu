# 12-pointers-zero-values-nil-gotchas

## Overview
This is a mini-project demonstrating 12 pointers zero values nil gotchas.

## Usage

### Run App
Run the application using the CLI:

```bash
go run ./cmd/app/main.go [flags]
```

### Run Dev/Debug
Run the development harness:

```bash
go run ./cmd/dev/main.go
```
