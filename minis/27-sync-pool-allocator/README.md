# 27: sync.Pool Allocator

## What Is This Project About?

This module teaches you how to use sync.Pool for object reuse.

## Key Concepts

- **sync.Pool**: Temporary object pool
- **Object reuse**: Reducing allocations
- **GC pressure**: Minimizing garbage
- **Use cases**: Buffer pools, parser pools

## How to Run

```bash
go run ./cmd/dev/main.go
```
