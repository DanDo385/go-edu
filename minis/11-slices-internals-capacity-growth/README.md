# 11-slices-internals-capacity-growth

## Overview
This is a mini-project demonstrating 11 slices internals capacity growth.

## Usage

### Run App
Run the application using the CLI:

```bash
go run ./cmd/app/main.go [flags]
```

### Run Dev/Debug
Run the development harness:

```bash
go run ./cmd/dev/main.go
```
