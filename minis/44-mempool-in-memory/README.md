# 44: Mempool In-Memory

## What Is This Project About?

This module teaches you how to build an in-memory transaction mempool.

## Key Concepts

- **Transaction pool**: Pending transaction storage
- **Priority ordering**: Gas price sorting
- **Size limits**: Eviction policies
- **Nonce tracking**: Per-account transaction order

## How to Run

```bash
go run ./cmd/dev/main.go
```
