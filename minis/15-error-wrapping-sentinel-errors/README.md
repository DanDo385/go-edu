# 15: Error Wrapping and Sentinel Errors

## What Is This Project About?

This module teaches you Go's error handling patterns including wrapping and sentinel errors.

## Key Concepts

- **Error interface**: Basic error handling
- **Wrapping errors**: fmt.Errorf with %w
- **Unwrapping**: errors.Is and errors.As
- **Sentinel errors**: Predefined error values

## How to Run

```bash
go run ./cmd/dev/main.go
```
