# 47: Plugin System Hot Reload

## What Is This Project About?

This module teaches you how to build a plugin system with hot reloading.

## Key Concepts

- **plugin package**: Loading shared objects
- **Hot reload**: Replacing code at runtime
- **Interface contracts**: Plugin API
- **Limitations**: Linux/macOS only

## How to Run

```bash
go run ./cmd/dev/main.go
```
