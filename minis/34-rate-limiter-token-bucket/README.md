# 34: Rate Limiter - Token Bucket

## What Is This Project About?

This module teaches you how to implement a token bucket rate limiter.

## Key Concepts

- **Token bucket algorithm**: Tokens replenish over time
- **Rate limiting**: Controlling request rate
- **Burst handling**: Allowing temporary spikes
- **golang.org/x/time/rate**: Standard library rate limiter

## How to Run

```bash
go run ./cmd/dev/main.go
```
