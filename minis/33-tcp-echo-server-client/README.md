# 33: TCP Echo Server/Client

## What Is This Project About?

This module teaches you low-level TCP networking with a simple echo server.

## Key Concepts

- **net.Listener**: TCP server
- **net.Dial**: TCP client
- **Connection handling**: Read/Write loops
- **Concurrency**: Handling multiple clients

## How to Run

```bash
go run ./cmd/dev/main.go
```
