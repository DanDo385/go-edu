# 43: Proof of Work Demo

## What Is This Project About?

This module teaches you how proof of work mining works.

## Key Concepts

- **PoW algorithm**: Finding nonce with target hash
- **Difficulty**: Leading zeros requirement
- **Mining loop**: Incrementing nonce
- **Verification**: Checking work is valid

## How to Run

```bash
go run ./cmd/dev/main.go
```
