# 40: Merkle Tree Basics

## What Is This Project About?

This module teaches you how to build a Merkle tree data structure.

## Key Concepts

- **Merkle trees**: Hash trees for verification
- **Root hash**: Single hash of all data
- **Proofs**: Efficient subset verification
- **Use cases**: Blockchain, file verification

## How to Run

```bash
go run ./cmd/dev/main.go
```
