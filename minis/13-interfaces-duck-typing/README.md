# 13: Interfaces and Duck Typing

## What Is This Project About?

This module teaches you Go's interface system and duck typing philosophy.

## Key Concepts

- **Interface definition**: Method sets
- **Implicit satisfaction**: No explicit implements
- **Duck typing**: If it walks like a duck...
- **Empty interface**: interface{} and any

## How to Run

```bash
go run ./cmd/dev/main.go
```
