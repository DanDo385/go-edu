# 41: Signed Transactions - Ed25519

## What Is This Project About?

This module teaches you digital signatures using Ed25519.

## Key Concepts

- **Ed25519**: Fast elliptic curve signatures
- **Key pairs**: Public/private key generation
- **Signing**: Creating signatures
- **Verification**: Validating signatures
