# 45: P2P Gossip Mock Network

## What Is This Project About?

This module teaches you how to build a gossip protocol for message propagation.

## Key Concepts

- **Gossip protocol**: Epidemic message spreading
- **Peer connections**: Mesh network
- **Message deduplication**: Seen message tracking
- **Reliability**: Ensuring delivery
