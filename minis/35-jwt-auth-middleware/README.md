# 35: JWT Auth Middleware

## What Is This Project About?

This module teaches you how to build JWT authentication middleware.

## Key Concepts

- **JWT tokens**: JSON Web Tokens
- **Middleware**: HTTP handler wrapping
- **Claims validation**: Expiry, issuer checks
- **Token generation**: Signing JWTs

## How to Run

```bash
go run ./cmd/dev/main.go
```
