# 42: Simple Block Struct Hashing

## What Is This Project About?

This module teaches you how to create hashable block structures.

## Key Concepts

- **Block structure**: Header, body, hash
- **Hash chaining**: Parent hash linking
- **Serialization**: Consistent byte encoding
- **Verification**: Block hash validation

## How to Run

```bash
go run ./cmd/dev/main.go
```
