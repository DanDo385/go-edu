# 37: HTTP Middleware Chain

## What Is This Project About?

This module teaches you how to build composable HTTP middleware chains.

## Key Concepts

- **Middleware pattern**: Handler wrapping
- **Chaining**: Composing multiple middleware
- **Request context**: Passing data through chain
- **Common middleware**: Logging, auth, recovery

## How to Run

```bash
go run ./cmd/dev/main.go
```
