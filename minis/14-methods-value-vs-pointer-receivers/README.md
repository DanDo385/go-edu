# 14: Methods - Value vs Pointer Receivers

## What Is This Project About?

This module teaches you when to use value receivers vs pointer receivers for methods.

## Key Concepts

- **Value receivers**: Copy of the struct
- **Pointer receivers**: Reference to the struct
- **Mutation**: Only pointer receivers can modify
- **Consistency**: When to use which

## How to Run

```bash
go run ./cmd/dev/main.go
```
