# 32: WebSocket Chatroom

## What Is This Project About?

This module teaches you how to build a WebSocket-based chat application.

## Key Concepts

- **WebSockets**: Full-duplex communication
- **gorilla/websocket**: WebSocket library
- **Broadcasting**: Sending to multiple clients
- **Connection management**: Tracking clients

## How to Run

```bash
go run ./cmd/dev/main.go
```
